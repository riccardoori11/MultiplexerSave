A helper process held an exclusive flock on atlas. A real work init atlas opened that file and waited while work init beta completed. Killing the helper let the atlas initialization finish. The lock file remained on disk.

The execution lab models these mechanics in JavaScript. The process order, signal injection and non-EINTR error are illustrative schedules.
